# Live block captures — 2026-09-18

What Aura actually looked like in production on the day the Instrument
direction was chosen. Every image is the deployed app at
`https://aura-weather-platform.netlify.app/`, not a mockup and not a local
build, so a later reader can check a proposal against the real thing
rather than against someone's memory of it.

This folder exists because of a specific mistake. The first round of
Instrument mockups was drawn from an abstracted idea of the dashboard and
quietly dropped the forecast's week control, the radar block entirely, and
most of the hourly card's furniture — the tabs, the legend, the NOW
marker, the hour strip. Jenna had to send screenshots to show what was
missing. Anything proposing a change to these blocks should open the
matching capture first.

## How they were taken

Playwright, Chromium, desktop viewport 1440×1000 and mobile 390×844, both
at device scale factor 1, `reducedMotion: "reduce"` so entrance animations
do not catch a card mid-transform, and a settle wait after `networkidle`
so radar tiles and chart paths have painted.

JPEG at quality 88 rather than PNG: at full size the set came to 14 MB of
PNG for no readable gain, and these are reference photographs of a UI, not
pixel-diff baselines. `docs/screenshots/` remains the home of the
deterministic, README-embedded PNGs regenerated by `npm run screenshots` —
this folder is a dated snapshot and is not regenerated by anything.

Live weather is live, so re-running this on another day produces different
readings, a different alert set and different radar echoes. That is fine
for the purpose; it is not fine for anything that wants to compare pixels.
